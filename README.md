# Planck: Automated Scientific Discovery System

**Planck** is an AI-driven scientific reasoning engine. It assumes nothing about the world except that it produces data. It tests "Common Sense" hypotheses by trying to fit them to observed data and reporting when they break.

Planck does not know "Physics". It knows Logic and Statistics. It discovers that certain observed data patterns are **mathematically impossible** to explain using standard intuitive assumptions (Factorizability, Logic, History).

## Experiments

### 1. Experiment Zero: The Factorization Failure (Bell-CHSH)
**Observation**: Correlations between two separated binary outputs ($A, B$) given inputs ($X, Y$).
**Hypothesis Tested**: "Outcomes are generated by local functions of inputs and shared history."
**Discovery**: Planck runs an optimizer to find the maximum correlation sum possible for *any* such model (empirically found to be 2.0). It observes a sum of ~2.8, proving that **no factorizable model** can explain the data.

### 2. Experiment One: The Logic Gate Contradiction (GHZ)
**Observation**: Three binary inputs ($0/1$) and outputs ($\pm 1$).
**Hypothesis Tested**: "Outcomes are determined by a fixed truth table logic."
**Discovery**: Planck identifies strict input-output rules (e.g., $Input(0,1,1) \to Product +1$). It attempts to solve for a truth table that satisfies these rules and finds a logical contradiction (Prediction $+1 \neq$ Observation $-1$).

### 3. Experiment Two: The History Paradox (Temporal)
**Observation**: Sequential measurements of a single system at different times.
**Hypothesis Tested**: "The system possesses a definite value at all times, independent of measurement."
**Discovery**: Planck enumerates all possible history vectors $v(t) \in \{\pm 1\}$ and finds the maximum consistency metric ($K$) is 1.0. It observes $K \approx 1.5$, proving that **measuring the system changes its history**.

## Usage
    
**1. Active Discovery (Experiment Zero - Bell)**:
The system autonomously searches for experimental settings that violate classical local realism.
```bash
# Run Active Loop (Search for Violation)
python3 src/active_discovery_zero.py

# Run Constraint Discovery (Find Mathematical Reason)
python3 src/constraint_discovery.py
python3 src/symbolic_discovery.py

# Run Safety Guardrails (Verify Result)
python3 src/guardrails.py
```

**2. Manual Experiments**:
```bash
# Experiment One (GHZ Logic)
python3 src/ghz_simulator.py --trials 5000
python3 src/ghz_inference.py

# Experiment Two (Temporal History)
python3 src/temporal_simulator.py --trials 3000
python3 src/temporal_inference.py
```

## Philosophy
Planck strictly separates **Observation** (Inputs/Outputs) from **Inference**. It never assumes a "Quantum State" or "Wavefunction". It only asserts that a Model Class (e.g., Local Hidden Variables) is statistically inconsistent with the data.
